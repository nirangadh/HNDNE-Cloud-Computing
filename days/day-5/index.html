THARA TODAY

The key that is switched off

Since Day 2 a key with the full power of your account has been sitting in a text file on Thara's web server. It is switched off, and it still exists. The Data Protection Officer has three questions, and that key fails all of them: who can read patient data, what protects it if a disk is copied, and how would we know if someone tried? Today each question gets an answer you can show him.
