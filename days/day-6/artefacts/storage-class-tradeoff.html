Storage class trade-off

Thara adds laboratory reports to thara-reports-<student id> every month and keeps each one for a time. Move the slider to say for how long. Each bar is the monthly storage bill, for every 100 GB of reports added each month, if all of them sat in that class. Then read the labels under the bar: the cheapest class to keep is never the quickest to open.

The bars count storage and nothing else. Requests, and the charge for each gigabyte read back from every class except S3 Standard, come on top. Thara Hospitals is fictional.
