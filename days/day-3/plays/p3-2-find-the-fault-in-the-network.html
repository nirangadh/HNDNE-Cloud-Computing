Find the fault in the network

LO5LO7

Four things from this afternoon's lab, as somebody else left them: the route tables, a network ACL, a security group, and a student's notes on four flow log records. Each has something wrong in it, and at least one line that only looks wrong.

How to play
  1. Read the exhibit. Press each line you think is a fault; press again to clear it. The arrow keys move between lines.
  2. Choose Check my flags. A fault found scores a point. A good line flagged by mistake takes one away.
  3. Every fault, and every false alarm, comes with its reason.
