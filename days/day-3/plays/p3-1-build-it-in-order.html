Build it in order

LO5LO7

This morning the wizard built a network in one click, and then the same network was built by hand. Here are six steps of the hand build for thara-vpc, shuffled. This afternoon you do them yourself.

How to play
  1. Put the steps in the order that works, first step at the top. Use the arrow buttons, or focus a step, press Space to lift it, the arrow keys to move it and Space to drop it.
  2. Choose Compare my order. You are scored against the order the Head of IT would use, which is the lab's order, one point for each step in the same place.
  3. One pair of steps would work either way round in the console. The reason the lab puts them as it does is given with the result.
